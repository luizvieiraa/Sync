## Compilar e executar

No Linux, Unix, macOS ou Ubuntu/WSL, com compilador C, pthreads e Make:

```sh
cd lhcv
make clean
make
./sync_car
```

O executável não recebe argumentos nem arquivo de entrada. A saída é a do
runner original e deve terminar com `Looks good!`.
